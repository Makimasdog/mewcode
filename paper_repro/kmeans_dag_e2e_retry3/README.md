# K-Means Reproduction

This is a minimal reproduction of the k-means algorithm as described in the paper.

## Implementation Details
- Basic k-means algorithm with random initialization
- Synthetic data generation with 3 clusters
- Convergence checking based on centroid movement
- Inertia calculation (sum of squared distances)

## Usage

```bash
python kmeans.py
```

## Expected Output
- Data shape information
- Number of iterations
- Inertia value
- Accuracy comparison with true labels
