### SECTION 2.1 EXCERPT:
**[PDF PAGE 3]** "Let z₁, z₂, ... be a random sequence of points (vectors) in E^N, each point being selected independently of the preceding ones using a fixed probability measure p."

> "Define a minimum distance partition S(x) = {S₁(x), S₂(x), ..., Sₖ(x)} of E^N, by Sᵢ(x) = Tᵢ(x) \ S₁(x)... where Tᵢ(x) = {z ∈ E^N : |z - xᵢ| ≤ |z - xⱼ|, j = 1, 2, ..., k}. The set Sᵢ(x) contains the points in E^N nearest to xᵢ, with tied points being assigned arbitrarily to the set of lower index."

> "xᵢⁿ⁺¹ = (Wᵢⁿ x̄ᵢⁿ + zₙ₊ₖ) / (Wᵢⁿ + 1), Wᵢⁿ⁺¹ = Wᵢⁿ + 1, and xⱼⁿ⁺¹ = xⱼⁿ for j ≠ i"

> "Stated informally, the k-means procedure consists of simply starting with k groups each of which consists of a single random point, and thereafter adding each new point to the group whose mean the new point is nearest."

**Initialization:** First k centers = first k data points (xᵢⁿ = Zᵢ, W₍ᵢ₎ = 1). One-pass online streaming update.

**Tie breaking:** "tied points being assigned arbitrarily to the set of lower index." If xᵢ = xⱼ and i < j then Sⱼ(x) = ∅.

**Online update formula:** New centroid = old_center * old_weight + new_point, divided by (old_weight + 1). Only the winning cluster's center changes per point.

### SECTION 3.4 EXCERPT:
**[PDF PAGE 13]** "As a scrambled dimension test for independence among several variables... First, the sample points are grouped into a minimum distance partition using k-means, and the within-class variance is determined."

> "To illustrate this method, a sample of 150 points was prepared in which points were distributed uniformly outside a square 60 units on a side, but inside a surrounding square 100 units on a side."

> "This gave a sample which involves essentially a zero correlation coefficient, and yet a substantial degree of relationship... The above procedure was carried out using k-means with k = 12."

> "As was expected, the variance after scrambling was increased by a factor of 1.6."

> "Using k = 6, 12, and 18, the within-class variance increased after scrambling by the factors 1.40, 1.55, and 1.39, respectively."

**Square-ring experiment:** 150 points uniform in [−50, 50]² excluding (−30, 30)². k = 12. Scrambled ratio observed by author: **1.6**. Paper also applied to a 5D sample with k = 6, 12, 18 giving ratios 1.40, 1.55, 1.39.

**Non-parametric test proposal:** Repeat scrambling n times; the rank of unscrambled WCSS among n+1 values should be uniformly distributed under H₀. Example: if unscrambled variance is the lowest of 19 scrambled, reject independence at Type I error = .05.
